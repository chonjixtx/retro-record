# 回溯 All-in-One deb 使用说明

一个 deb = **游戏内悬浮窗插件 + 回溯 App 本体（含录屏内核）**。装一次，之后日常使用
**不需要再打开桌面上的「回溯」图标**。

---

## 一、装哪个

| 你的越狱 | 用哪个文件 |
|---|---|
| dopamine / palera1n（rootless） | `回溯AllInOne-rootless.deb` |
| roothide | `回溯AllInOne-roothide.deb` |

不确定就两个都下，装错的表现是「装成功但游戏里不出球」，不会弄坏机器，卸掉换另一个即可。

**前置**：需要装 AppSync Unified（未签名 App 才能被系统接受）。Sileo 里搜 `AppSync Unified`
安装即可，主流源都有。

---

## 二、安装

```
1. 把 deb 传到设备（Filza / 隔空投送 / Sileo 本地安装都行）
2. 点开安装（或 dpkg -i）
3. killall backboardd        （或 sbreload / uicache -a）
4. 桌面会出现「回溯」图标 —— 它必须存在（系统靠它找到录屏内核），但日常不用点
```

---

## 三、日常使用流程

```
1. 打开球球大作战，等约 2.5 秒，屏幕左侧中间出现黑色圆球
2. 点圆球 → 展开面板
3. 点「① 开启录屏」左边的控件 → 系统「开始直播」面板直接弹在游戏上
4. 选「回溯录制」→ 点「开始直播」          ← 这两下必须你手动点，系统设计如此
5. 面板收起，你还在游戏里，录制已经开始了
6. 想保存：点圆球 → 「保存最近 60 秒」
7. 视频进相册「最近项目」最前面
```

要调时长 / 码率，直接在面板里改（③ ④ 两行），不用切出游戏。

---

## 四、交互速查

| 操作 | 效果 |
|---|---|
| 点圆球 | 展开 / 收起面板 |
| 长按圆球 0.8 秒 | 立刻保存，不用展开面板 |
| 拖动圆球 | 挪位置（位置会记住） |
| 面板「收起」 | 只收面板，圆球还在 |

---

## 五、兜底机制

点保存后：

- **1.8 秒内收到录制进程回执** → 弹「录制进程已收到，正在保存 N 秒」，游戏完全不切走
- **没收到回执**（没在录 / 广播被系统杀掉）→ 自动拉起「回溯」App 兜底保存，
  弹「未检测到录制进程，已切到『回溯』保存」

**也就是说，点下去一定会有视频**，最坏情况只是短暂切出游戏 1–2 秒。

---

## 六、排查

```
ls /var/jb/Library/MobileSubstrate/DynamicLibraries/ | grep Retro     # 插件在不在
ls /var/jb/Applications/                                              # App 在不在
uicache -a && killall backboardd                                      # 刷新注册
log stream | grep -i RetroSave                                        # 看注入报错
```

| 现象 | 原因 / 处理 |
|---|---|
| 游戏里不出球 | deb 装错版本（rootless / roothide 搞反），或 plist 的 Bundle ID 不对 |
| 弹不出「开始直播」列表 | App 没注册成功：`uicache -a` 后 respring 再试 |
| 录上了但保存没视频 | 扩展相册权限问题；用「回溯」App 诊断区看 `AUTH_` 那一行 |
| 装了但图标不出现 | 没装 AppSync Unified |

---

## 七、退路

如果 deb 装的 App 里那个广播扩展**系统不认**（「开始直播」列表里没有「回溯录制」），
说明这种方式在你的越狱上不生效。退路：

1. 用巨魔装 `ballsios回溯-buildXX.ipa`（App 本体）
2. 只装插件 deb（`RetroSaveInGame-*.deb`）

功能体验完全一样，只是多一步装 ipa。
